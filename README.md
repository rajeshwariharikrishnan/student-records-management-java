# student-records-management-java
A beginner-friendly Java project to manage student records, search students, and analyze marks using basic programming concepts and object-oriented programming.
## Features
- Add student details
- Search for a student
- Store student marks
- Calculate average marks
- Find the highest scorer

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Learning Goals
This project is built to practice Java programming, arrays, methods, and basic problem-solving skills.
